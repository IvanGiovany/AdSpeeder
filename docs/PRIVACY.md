# Privacy statement

AdSpeeder collects no data and sends no telemetry. There is no account, analytics service,
remote configuration, advertising SDK or external reporting endpoint.

Settings and ad/time-saved statistics stay in the browser's local extension storage. Daily
statistics are retained for 30 days; aggregate all-time totals remain until reset. Debug logging
is opt-in: up to 50 events remain in each supported page's memory until that page closes.
A JSON export is downloaded only when requested and remains on your device unless you share it.

The extension reads supported player DOM state and locally reads YouTube player metadata to
recognize ads. It changes video speed and mute state, then restores previous settings. It does
not block requests or alter network traffic. Host access is limited to the registered YouTube
and Netflix hosts. Browser/platform traffic continues independently of this extension.

Reset statistics or settings in Options; uninstalling removes the extension's local storage.
